# oltech24.ru

Сайт OLTECH: статические страницы, хостинг — GitHub Pages (ветка `main`, корень репозитория).

- `index.html` — главная
- `kartochki/`, `lendingi/`, `ceny/`, `privacy/`, `zapis/` — разделы
- `portfolio/` — концепты сайтов для портфолио (noindex)
- `assets/` — стили, скрипты, шрифты, картинки
- `CNAME` — домен для GitHub Pages, не удалять
- `404.html` — страница «не найдено»

Изменения в `main` появляются на сайте через 1–2 минуты.
Защита (CSP) задаётся тегом `<meta http-equiv="Content-Security-Policy">` в каждой странице.
Стили и скрипты подключаются с `?v=N`: при изменении CSS/JS номер повышаем.
Контакт для всех кнопок задаётся в `assets/js/main.js` → `CONTACT.telegram`.
Пароли, токены и ключи в репозиторий не кладём: репозиторий публичный.
