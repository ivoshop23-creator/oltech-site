# oltech24.ru

Сайт OLTECH: статические страницы на nginx в Docker.

- `index.html` — главная
- `kartochki/` — карточки для WB и Ozon, калькулятор
- `assets/` — стили, скрипт, шрифты, картинки
- `nginx.conf` — заголовки безопасности, кэш, сжатие
- `Dockerfile` — сборка для Easypanel

Контакт для всех кнопок задаётся в `assets/js/main.js` → `CONTACT.telegram`.
Пароли, токены и ключи в репозиторий не кладём.
